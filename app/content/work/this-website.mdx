The site you are looking at. A personal portfolio that behaves like a
unix terminal and looks like a CRT monitor.

- **Stack**: React 19, React Router framework mode (SPA + prerender),
  TypeScript strict, MDX content, raw WebGL2.
- **Features**: simulated shell with tab completion and man pages,
  eleven terminal color themes, tunable CRT effects, full keyboard
  navigation, and a semantic DOM layer for accessibility and SEO.
- **Quality**: unit tests on the shell/VFS/themes/engine math, ESLint,
  strict typechecking, CI deploys to GitHub Pages.
